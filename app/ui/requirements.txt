# Deployment-only dependencies for Streamlit Community Cloud.
#
# Community Cloud installs dependencies from the requirements file closest to
# the entrypoint (`app/ui/streamlit_app.py`), which is this file; the root
# requirements.txt is NOT read when this file exists. We therefore include the
# root file explicitly so there is a single source of truth for the app's
# dependencies, and only override what the Linux cloud runners need.

# Linux CPU-only wheels. The default PyPI wheels pull in multi-gigabyte CUDA
# libraries that exceed the platform's build limits; BlueEye's inference is
# CPU-only anyway (app/config.py falls back to CPU when CUDA is unavailable).
# Pins match the locally tested environment (Python 3.12, torch 2.13.0+cpu,
# torchvision 0.28.0+cpu); wheels were verified to exist for Linux cp312/cp311.
--extra-index-url https://download.pytorch.org/whl/cpu

-r ../../requirements.txt

torch==2.13.0+cpu
torchvision==0.28.0+cpu

# Pin Streamlit to the locally tested version. BlueEye's design system
# (app/ui/theme.py) styles Streamlit's widget DOM (radio nav groups, icons),
# and newer Streamlit releases change that markup; a 2026-10 deploy silently
# picked up 1.66.x and rendered the sidebar unstyled. The root requirements.txt
# keeps the compatible range (>=1.49) for local development.
streamlit==1.61.1
